# 校准参考照片需求

摄影作品由项目所有者提供。当前没有把其他来源的摄影或 AI 照片当作校准参考素材。

## 建议首批选片

| 类别 | 建议画面 | 用途 |
| --- | --- | --- |
| 中性色 | 阴天建筑、灰墙、白纸、金属或灰色织物；尽量避免彩色灯反射 | 判断灰阶偏色和中性平衡 |
| 自然肤色 | 自然窗光或柔和日光中的人物，保留脸部层次 | 观察偏绿、偏红及肤色连续性 |
| 暗部 | 夜间街景、昏暗室内、深色衣物，暗处仍有可辨细节 | 观察暗部压黑、偏色、层次丢失 |
| 高光 | 白云、雪、白色衣物或逆光窗帘，亮处保留纹理 | 观察高光裁切与亮部层次 |
| 饱和色 | 花、植物、水果、彩色街景，同时包含不过曝的红绿蓝 | 检查色彩关系和过饱和感 |
| 平滑渐变 | 天空、雾、水面；尽量少后期压缩和过度降噪 | 辅助观察色带和渐变 |
| 综合对比 | 同时有灰色物体、肤色/自然色和明暗细节的日常画面 | 最终前后对比 |

每类先选 1–2 张，共约 8–12 张即可。场景覆盖比照片数量更重要。

## 文件与处理

- 保留原始文件或高质量母版；首批 SDR 发布素材建议使用嵌入 sRGB profile 的高质量 JPEG 或 PNG，长边约 3000–4000 px。
- 同一照片的预览和全屏版本由同一母版导出，保留一致颜色转换；不在 UI 中自动增强、滤镜、白平衡或过度锐化。
- 提供照片标题、拍摄光线和希望观察的细节。作者署名与素材许可单独记录；未经约定不自动套用代码许可证。
- 需要保留暗部和高光的自然层次，避免已经大面积裁切或刻意强烈调色的照片作为基础校准例图。
- 后续 HDR 素材单独管理，明确传递函数、色域与亮度信息。

照片用于视觉检查，不能代替测量仪器或已知数值的校准图。Gamma 图、黑白阶梯、RGB 通道图等由程序绘制。素材放入 `assets/reference-photos/` 后再建立内容清单；当前只保留目录说明。
